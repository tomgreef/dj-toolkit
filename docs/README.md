| [architecture.md](architecture.md) | You need to know how it fits together, or where a change goes |
| [testing.md](testing.md) | You're writing a test, or CI is red |
| [vibe-coding.md](vibe-coding.md) | You work with an AI coding agent |

| [releasing.md](releasing.md) | You're publishing a new version |
| [ux/](ux/README.md) | You're changing anything a user sees or reads: persona, voice, decisions |
