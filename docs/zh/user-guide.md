# 用户指南

本指南是简体中文译文，译自英文版用户指南（v0.1.1，该页最后一次修改在提交 `b66c082`）。两者不一致时，以[英文版](../user-guide.md)为准。

这款应用的所有功能，尽在这一页。在 macOS 上，请将所有显示 Ctrl 的地方替换为 Cmd（⌘）。

## 清唱（Acapella）准备：两步走

在节拍最清晰的地方对齐最省力，所以你需要一边听，一边在副歌处进行对齐操作。

**1. 锁定节拍网格（Lock the grid）。** 应用会在曲目声音最大的部分建议四个节拍。按 **空格键** 播放：这四个节拍会循环播放，同时网格上会响起 **节拍器（Click）** 的声音，这样你就能听出它们是否踩在音乐上了。拖动标记点来修正（拖动时能听到声音），或者清除标记并连续点击四个节拍，又或者跟着音乐敲击 **B 键**。用心找准的四个节拍将定下整首曲目的速度（Tempo）*以及* 网格的相位（Phase）。

**2. 设置起点（Set the start）。** 点击人声切入的那个节拍；它会自动吸附到网格上。预备拍（Count-in）就是它前面的几个节拍：可以是一段节拍器声音、静音或是你自己的采样。**预览（Preview）** 会先播放预备拍，然后播放人声。**导出（Export）** 会写入 WAV、FLAC 或 MP3 格式文件，命名为 `Name - 128bpm.ext`，并写入 BPM 标签信息。

| 操作 | 方法 |
|---|---|
| 来回搓碟（Scratch） | 拖动波形图顶部的滚动条 |
| 缩放 / 平移 | 鼠标滚轮 / Shift+滚轮 或 右键拖动 |
| 微调标记点 | 点击它，然后按 `←` `→`（按住 Shift：1 毫秒，按住 Ctrl：100 毫秒） |
| 修正倍速或半速识别错误 | **Half（半速）** / **Double（倍速）** |
| 切换页面 | `Ctrl+1` `Ctrl+2` `Ctrl+3` |
| 打开、预览、导出 | `Ctrl+O`, `Ctrl+P`, `Ctrl+E` |

## Spotify 同步：每个文件夹都会变成一个播放列表

1. **关联 Spotify（Link Spotify）。** 六步向导会引导你创建一个 Spotify 应用，将其重定向 URI（Redirect URI）设置为 `http://127.0.0.1:8888/callback`，粘贴客户端 ID（Client ID）并批准访问权限。如果你通过“更多（More）”更改了回调端口，请同步更新此 URI 以保持一致。
2. **选择你的音乐文件夹。** 里面的每一个子文件夹都会变成一个播放列表。
3. 先 **预览更改（Preview changes）**。**同步播放列表（Sync playlists）** 只有在预览后才会解锁，因为同步会移除文件夹中已不存在的曲目。更改任何设置都会要求重新预览。你的音乐文件绝不会被修改。
4. Spotify 限制了新应用每天可以进行的搜索次数。在你的曲库匹配完成之前，请将 *每次运行的 Spotify 搜索次数（Spotify searches per run）* 保持在 150 次左右。匹配过的记录会被记住，在匹配完成前不会移除任何内容。

从旧的命令行工具迁移过来？**更多（More）** 页面提供了 *导入旧工具的 .env（Import the old tool's .env）* 和 *导入旧工具的搜索记录（Import the old tool's searches）* 功能，这样你之前匹配过的曲目就不会再次被搜索。

## 教程（Tutorials）

每篇都带有一条核心建议的简短指南：文件夹结构、将文件夹导入 rekordbox、从 rekordbox 导入 U 盘、清唱（Acapellas）以及 Spotify 播放列表。不同意某条建议？在下方发表问题或提出挑战。你会以 *匿名 DJ #xxxx* 的身份出现，目前帖子仅保存在你的电脑本地。

## 需求与反馈（Requests）

为你希望接下来开发的功能投票。页面会列出最受期待的创意（均为 GitHub issue）；点击 **投票（Vote）** 会在 GitHub 上打开它，点赞即算作一票（你需要一个免费的 GitHub 账号）。**建议新功能（Suggest a feature）** 和 **报告 Bug（Report a bug）** 会在 GitHub 上打开简短的反馈表单，并已预先填好你的应用版本号。应用绝不会要求你登录，且仅当你打开该页面时才会拉取列表。

## 记忆功能（What it remembers）

它会记住你处理过的每个文件的四个节拍和起点、每个对话框上次使用的文件夹（如果文件夹丢失会有备用路径）、你的预备拍和导出选项、窗口大小、当前页面、上次查看的教程以及外观设置。在 Windows 上，这些数据保存在 `%APPDATA%\DJToolkit`；在 macOS 上，保存在 `~/Library/Application Support/DJToolkit`。删除该文件夹即可从头开始。

## 外观（Looks）

侧边栏中的 **外观（Appearance）** 开关允许你选择 **Booth（暗色/现场模式，适合夜店和深夜备歌）** 或 **Daylight（亮色/日光模式，高对比度，适合白天派对）**。下方的圆点用于选择强调色（主题色）。
